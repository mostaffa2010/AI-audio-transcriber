# FlowMate Audio Transcriber

Installable PWA that transcribes Arabic audio with Groq Whisper and gives accurate timestamps.

- Output format: `[mm:ss.mmm → mm:ss.mmm] text`
- Word timings are snapped to the audio's real speech, so words never sit on the wrong side of a long pause
- Doubtful lines are highlighted (low confidence, repetition, mostly silence)
- Export word timings as JSON; cut sentences and rebuild the audio
- Works offline (app shell), supports "Share to app" for audio files on Android

## Hosting
Static files only. Serve the folder over HTTPS (e.g. GitHub Pages) and open it on the phone, then
*Install app* (Android/Chrome) or *Share → Add to Home Screen* (iPhone/Safari).
All paths are relative, so it works from a sub-path such as `/AI-audio-transcriber/`.

When you change files, bump `VERSION` in `sw.js` so installed copies refresh.

Icons are generated by `python3 tools/make_icons.py`.
